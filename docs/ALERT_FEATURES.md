# 告警管理系统功能特性

## 系统概述
告警管理系统是ColdChain Guardian冷链仓储安全管理系统的核心监控模块，提供了全方位的异常检测、智能分析和应急响应功能。

## 主要功能模块

### 1. 告警中心
- **顶部告警雷达**：多维度KPI卡片显示未处理告警、紧急/高危告警、处理中告警、今日已消除告警
- **智能分析面板**：包含趋势分析、重复告警、设备健康度、根因分析四个维度
- **复合筛选栏**：支持按关键词、发生位置、告警级别、处理状态、时间范围等多维度筛选
- **高密度告警列表**：展示告警级别、内容、发生位置、时间、状态等详细信息
- **分页处理**：支持大量告警的分页展示

### 2. 告警分析功能
- **趋势分析**：按时间段统计告警趋势，识别异常波动
- **重复告警分析**：识别高频告警，定位根本问题
- **设备健康度评分**：基于告警频率和级别评估设备健康状况
- **根因分析**：识别同时发生的相关告警，定位问题根源

### 3. 告警处理机制
- **告警研判抽屉**：提供详细的告警信息和处理选项
- **转工单功能**：将复杂告警转化为工单进行长期跟踪
- **快速解决**：对简单问题进行快速处理
- **标记忽略**：对误报或无关紧要的告警进行忽略处理
- **处理历史记录**：完整记录告警处理过程

### 4. 告警状态管理
- **UNHANDLED（未处理）**：新产生的告警状态
- **HANDLING（处理中）**：正在处理的告警状态
- **RESOLVED（已解决）**：已解决的告警状态
- **IGNORED（已忽略）**：被标记忽略的告警状态

### 5. 告警级别分类
- **CRITICAL（紧急）**：最高优先级，需要立即处理
- **HIGH（高）**：高优先级，需要尽快处理
- **MEDIUM（中）**：中等优先级，需要关注处理
- **LOW（低）**：低优先级，可延后处理

## 技术特点

### 后端技术栈
- **Spring Boot 4.x**：现代化的企业级应用框架
- **MyBatis-Plus**：增强的ORM框架
- **Java 17**：现代Java特性支持
- **事务管理**：确保数据一致性
- **定时任务**：自动化监控和处理

### 前端技术栈
- **Vue 3**：现代前端框架
- **Element Plus**：企业级UI组件库
- **Composition API**：现代化的组件编写方式
- **Axios**：HTTP客户端

### 核心算法实现
- **趋势分析算法**：基于时间序列的告警趋势分析
- **重复告警识别**：基于设备和告警类型的重复模式识别
- **设备健康度计算**：基于告警级别和频次的综合评分算法
- **根因分析算法**：基于时间窗口的相关告警聚类分析

## 数据库设计

### 告警主表 (alerts)
- 基础信息：ID、告警类型、告警级别、告警内容
- 状态信息：处理状态、处理人、处理时间
- 位置信息：库区、设备、详细位置
- 时间信息：首次发生时间、最后发生时间、创建时间
- 数值信息：当前值、阈值、告警次数

### 告警分析数据
- 趋势数据：按时间段统计的告警数量
- 重复告警数据：高频告警的设备和类型统计
- 设备健康评分：各设备的健康度评分
- 相关告警数据：基于时间窗口的告警关联关系

## API接口

### 告警管理API
- `GET /api/alerts/stats`：获取告警统计信息
- `GET /api/alerts/search`：搜索告警（支持多维度筛选）
- `PUT /api/alerts/{id}/status`：更新告警状态
- `PUT /api/alerts/{id}/convert-to-work-order`：将告警转为工单
- `GET /api/alerts/urgent`：获取紧急告警列表

### 告警分析API
- `GET /api/alerts/analysis/trend`：获取告警趋势分析
- `GET /api/alerts/analysis/recurring`：获取重复告警分析
- `GET /api/alerts/analysis/device-health`：获取设备健康度评分
- `GET /api/alerts/analysis/root-cause`：获取告警根因分析

## 前端组件

### 主要组件
- `AlertCenterView.vue`：告警中心主页面
- `AlertTriageDrawer.vue`：告警研判抽屉组件

## 使用场景

### 实时监控
1. 实时接收和展示各类告警
2. 通过告警雷达快速识别紧急问题
3. 根据级别和状态进行优先级排序
4. 及时处理高优先级告警

### 深度分析
1. 利用趋势分析了解系统运行规律
2. 通过重复告警分析定位顽固问题
3. 使用设备健康度评估设备维护需求
4. 借助根因分析快速定位问题源头

### 应急响应
1. 对紧急告警进行快速响应
2. 将复杂问题转为工单长期跟踪
3. 对误报进行合理标记
4. 形成完整的问题处理闭环
