# 库区管理页面实现

## 项目概述

库区管理页面是冷链仓储安全管理系统的重要组成部分，用于管理仓储区域的层级结构、阈值设置和设备关联等。

## 页面功能特性

### 1. 可视化库区层级
- 支持SITE → WAREHOUSE → FLOOR → AREA → BIN五级层级结构
- 左侧树形导航，右侧详情编辑
- 实时展示节点状态（启用/禁用、告警开关）

### 2. 搜索与过滤
- 支持按库区名称、编码搜索
- 支持按层级、状态过滤
- 高亮显示匹配节点

### 3. 节点操作
- **新增节点**：支持创建子节点或顶级节点
- **编辑节点**：修改节点基本信息、阈值设置
- **状态控制**：启用/禁用节点及子节点
- **移动节点**：调整节点在层级中的位置
- **删除节点**：支持软删除（禁用）操作

### 4. 阈值管理
- 支持温度和湿度阈值设置
- 提供继承父级阈值或自定义阈值的选项
- 可视化阈值范围展示

### 5. 批量操作
- 批量启用/禁用
- 批量开启/关闭告警
- 批量设置阈值策略

### 6. 数据导入导出
- 支持Excel格式批量导入
- 支持导出当前筛选结果
- 提供标准模板下载

## 技术实现

### 前端技术栈
- **框架**: Vue 3 + Composition API
- **UI库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios

### 页面结构

```
WarehouseAreaManage.vue
├── AreaTreePanel.vue (左侧树形导航)
├── AreaDetailPanel.vue (右侧详情)
│   ├── BasicInfoView.vue (基本信息查看)
│   ├── BasicInfoForm.vue (基本信息编辑)
│   └── ChildAreaTable.vue (子节点列表)
├── AreaEditDrawer.vue (新增/编辑抽屉)
├── MoveAreaDialog.vue (移动节点对话框)
└── ImportAreaDialog.vue (导入对话框)
```

### 核心功能实现

#### 1. 树形结构管理
- 使用Element Plus的Tree组件实现层级展示
- 支持异步加载和懒加载
- 提供右键菜单和行内操作

#### 2. 表单验证
- 使用Element Plus的Form组件
- 集成内置验证规则
- 支持自定义验证逻辑

#### 3. 权限控制
- 基于角色的权限管理
- 按钮级权限控制
- 页面级访问控制

#### 4. API集成
- 封装统一的API调用方法
- 集成错误处理和加载状态
- 支持请求拦截和响应处理

## API接口

| 接口 | 方法 | 功能描述 |
|------|------|----------|
| `/api/areas` | GET | 获取整棵库区树 |
| `/api/areas/{id}` | GET | 获取指定库区详情 |
| `/api/areas/parent/{parentId}` | GET | 获取子库区列表 |
| `/api/areas` | POST | 创建库区 |
| `/api/areas/{id}` | PUT | 更新库区 |
| `/api/areas/{id}` | DELETE | 删除库区 |
| `/api/areas/{id}/move` | POST | 移动库区 |
| `/api/areas/batch` | POST | 批量操作 |
| `/api/areas/export` | GET | 导出数据 |
| `/api/areas/import` | POST | 导入数据 |

## 使用说明

### 访问路径
```
http://localhost:8080/#/warehouse-area
```

### 操作流程
1. **浏览结构**：通过左侧树形结构查看库区层级
2. **查看详情**：点击节点查看详细信息
3. **编辑信息**：点击编辑按钮修改节点属性
4. **新增节点**：点击"新增"按钮添加子节点
5. **批量操作**：在子节点列表中选择多个节点进行批量处理

### 权限说明
- **ADMIN**: 完全权限，可进行所有操作
- **MANAGER**: 可创建、编辑、启用/禁用，但不能删除顶级节点
- **STAFF**: 只读权限，可查看和搜索
