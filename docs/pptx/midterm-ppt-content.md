## 第 3 页 - 项目概述

**标题：**
# 1. 项目概述

---

### 左栏：🎯 项目背景

- 冷链物流是食品安全重要保障
- 温湿度异常导致大量损耗
- 传统人工巡检效率低滞后性强
- 海量IoT数据需要智能化分析
- 毕业设计题目要求结合AI

---

### 右栏：💡 研究目标

- 构建完整冷链环境监测体系
- 建立智能预警机制
- 实现告警→工单闭环管理
- 集成大语言模型提供智能分析
- 完成Web端+小程序双端开发

---

### 底部：🏗️ 系统架构

```
物联网采集层 → 温湿度传感器 → MQTT协议上传
 后端服务层 → Spring Boot + MyBatis-Plus + MySQL + Redis
 前端应用层 → Vue 3 Web管理端 + 微信小程序员工端
 智能分析层 → Spring AI + 通义千问大语言模型
```

## 第 7 页 - AI大语言模型集成

**标题：**
# 5. AI大语言模型集成

---

### 🏗️ 集成架构

```
前端 → SSE流式请求 → AIAssistantController → AIAssistantService → Spring AI → 通义千问API
                          ↓
        会话历史 + 设备/告警业务上下文注入 → 大语言模型 → 流式token输出 → 前端打字机效果
```

---

### 三大核心特性

| 特性 | 说明 |
|------|------|
| 🌊 **流式输出(SSE)** | Server-Sent Events + Flux<String>，实现打字机效果，提升用户体验 |
| 🔍 **轻量级RAG** | 附件上下文动态注入，自动查询业务数据，丰富大模型回答内容 |
| 💾 **会话记忆管理** | 会话+消息分离存储，历史对话持久化，支持多会话切换 |

---

### ✅ 已解决的集成问题

1. **Spring AI版本依赖冲突** → 使用稳定里程碑版本，通过BOM统一管理依赖
2. **SSE流式输出403错误** → SecurityConfig配置 `DispatcherType.ASYNC.permitAll`
3. **API兼容性问题** → 适配Spring AI 1.0.0-M1标准API，保证稳定运行

## 第 8 页 - 物联网硬件接入

**标题：**
# 6. 物联网硬件接入

---

### 📟 硬件方案

- **传感器**：选用SHT30数字温湿度传感器
  - 测量范围：温度 -40℃ ~ +125℃，湿度 0% ~ 100%RH
  - 精度：温度 ±0.2℃，湿度 ±2%RH
  - I2C接口，通信稳定

- **主控**：ESP32-WROOM-32
  - 双核WiFi蓝牙，支持WiFi连接上传
  - 功耗低，适合电池供电
  - 开发生态完善，快速原型验证

- **供电**：USB 5V供电 / 锂电池供电可选

---

### 🔌 系统连接

```
SHT30传感器 → ESP32主控 → WiFi网络 → MQTT Broker → 后端服务 → 数据库存储
```

---

### 🔧 调试工作已完成

- ✓ 传感器驱动调试成功，数据读取稳定
- ✓ WiFi连接和MQTT上传调试成功
- ✓ 数据上传频率可配置（默认1分钟/次）
- ✓ 低功耗模式测试正常
- ✓ 实际环境温度湿度数据采集验证

### 📊 数据接入
