# 设备管理前端实现文档

## 1. 概述

本文档详细描述了ColdChain Guardian系统的设备管理前端实现，包括设备的增删改查、状态管理、阈值配置、数据展示、告警处理等功能。

## 2. 页面结构

### 2.1 主页面：DeviceManagementView.vue
- **路径**: `/devices`
- **功能**: 设备管理主页面，包含库区树、设备列表、筛选、操作等功能

### 2.2 设备数据页面：DeviceDataView.vue
- **路径**: `/devices/:deviceId/data`
- **功能**: 展示特定设备的温湿度数据、图表、历史记录

### 2.3 设备告警页面：DeviceAlertView.vue
- **路径**: `/devices/:deviceId/alerts`
- **功能**: 展示特定设备的告警信息、处理状态

## 3. 主要组件设计

### 3.1 页面布局结构

#### 3.1.1 顶部区域
- 面包屑导航：显示当前位置
- 页面标题：设备管理
- 刷新按钮：重新拉取数据

#### 3.1.2 左侧库区树
- 按库区层次结构组织
- 显示库区名称和层级标签
- 显示每个库区下的设备数量
- 点击库区自动筛选设备

#### 3.1.3 右侧设备列表
- 工具栏：包含新增、导入、导出、批量操作按钮
- 筛选区：多种筛选条件
- 表格：展示设备信息
- 分页器：支持分页浏览

### 3.2 功能特性

#### 3.2.1 设备管理功能
- **新增设备**: 通过对话框创建新设备
- **编辑设备**: 修改现有设备信息
- **删除设备**: 删除指定设备
- **启用/禁用**: 切换设备启用状态
- **告警开关**: 控制设备告警功能
- **批量操作**: 批量启用/禁用设备

#### 3.2.2 设备详情功能
- **基本信息**: 显示设备编码、名称、类型等
- **状态信息**: 显示在线状态、启用状态等
- **最新数据**: 显示最新温湿度数据
- **阈值配置**: 显示和编辑设备阈值

#### 3.2.3 阈值管理功能
- **继承/覆盖**: 支持继承库区阈值或设备自定义
- **灵活配置**: 温湿度上下限单独设置
- **实时生效**: 阈值修改立即生效

#### 3.2.4 数据展示功能
- **图表展示**: 温湿度变化曲线图
- **历史记录**: 详细的历史数据表格
- **时间筛选**: 按时间段查看数据
- **导出功能**: 支持数据导出

## 5. API 接口设计

### 5.1 设备相关接口 (deviceApi.js)
- `getList(params)`: 获取设备列表（分页）
- `getDetail(id)`: 获取设备详情
- `create(data)`: 新增设备
- `update(id, data)`: 更新设备
- `delete(id)`: 删除设备
- `updateStatus(id, enabled)`: 启用/禁用设备
- `updateAlarmStatus(id, alarmEnabled)`: 更新告警开关
- `updateThreshold(id, thresholdData)`: 更新阈值
- `batchUpdateStatus(ids, enabled)`: 批量更新状态
- `exportDevices(params)`: 导出设备
- `importDevices(formData)`: 批量导入

### 5.2 告警相关接口 (alertApi.js)
- `getByDeviceId(deviceId, params)`: 获取设备告警
- `getDetail(id)`: 获取告警详情
- `updateStatus(id, data)`: 更新告警状态
- `batchUpdateStatus(ids, data)`: 批量更新状态

## 6. 交互流程

### 6.1 设备筛选流程
1. 用户在左侧库区树选择库区
2. 右侧设备列表自动按库区筛选
3. 或使用筛选区的条件进行复合筛选

### 6.2 设备新增流程
1. 点击"新增设备"按钮
2. 打开新增设备对话框
3. 填写设备信息
4. 设置阈值配置（继承/覆盖）
5. 提交保存

### 6.3 阈值配置流程
1. 在设备列表点击"编辑阈值"
2. 打开阈值配置对话框
3. 选择"继承"或"覆盖"
4. 如选择"覆盖"，填写具体阈值
5. 保存配置

## 7. 数据校验

### 7.1 表单校验
- 设备编码：必填，3-50字符，字母数字下划线横线
- 设备名称：必填，2-100字符
- 所属库区：必填
- 阈值校验：下限 < 上限

### 7.2 业务校验
- 设备编码唯一性
- 阈值范围合理性
- 库区有效性

## 8. 权限控制

- **STAFF**: 只读权限，可查看设备和数据
- **MANAGER**: 可编辑、启停设备
- **ADMIN**: 全部权限，包括删除、导入导出

## 9. 异常处理

- **403**: 权限不足，提示用户联系管理员
- **401**: 登录失效，跳转登录页
- **409**: 设备编码重复，聚焦输入框提示
- **网络错误**: 统一提示网络异常

## 10. 性能优化

- 表格虚拟滚动（大数据量场景）
- 图表懒加载

- 适应不同屏幕尺寸
