# 库区管理页面演示与测试说明

## 演示准备

### 1. 环境要求
- Node.js >= 14.0
- npm 或 yarn
- 后端服务正常运行 (localhost:8080)

### 2. 前端项目初始化
```bash
# 进入前端目录
cd coldchain-guardian-web

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 3. 后端服务启动
```bash
# 进入后端目录
cd coldchain-guardian-server

# 启动后端服务
./mvnw spring-boot:run
```

## 页面访问路径

访问库区管理页面：
```
http://localhost:5173/warehouse-area
```

> 注意：前端默认端口为5173，后端端口为8080

## 常见问题及解决方案

### Q1: 页面加载后没有数据显示
**可能原因**: 后端服务未启动或API请求失败
**解决方案**:
1. 确保后端服务在localhost:8080运行
2. 检查浏览器控制台是否有网络错误
3. 确认token是否有效

### Q2: 操作按钮无响应
**可能原因**: 权限不足或数据加载失败
**解决方案**:
1. 检查当前用户权限
2. 刷新页面重新加载数据
3. 查看控制台错误信息

### Q3: 表单验证不通过
**可能原因**: 输入数据不符合验证规则
**解决方案**:
1. 检查输入数据格式
2. 确认必填字段已填写
3. 检查数值范围是否正确

1. **操作流畅性**: 按钮点击响应速度

3. **界面一致性**: 样式和交互保持统一

## 安全测试要点

1. **权限验证**: 确保无权限用户无法执行操作
2. **数据安全**: 敏感数据不被未授权访问
3. **输入验证**: 防止XSS等注入攻击
