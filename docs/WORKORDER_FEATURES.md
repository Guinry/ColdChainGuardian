# 工单管理系统功能特性

## 系统概述
工单管理系统是ColdChain Guardian冷链仓储安全管理系统的核心运维模块之一，实现了从告警到工单的闭环管理流程。

## 主要功能模块

### 1. 工单中心
- **多维度KPI看板**：显示逾期工单、待处理工单、处理中工单、本周已闭环工单等关键指标
- **复合筛选功能**：支持按工单类型、优先级、状态、责任人等多维度筛选
- **高密度数据表格**：展示工单的完整信息，包括类型、优先级、发生位置、责任人、时间节点、状态等
- **分页处理**：支持大量工单的分页展示

### 2. 工单全生命周期管理
- **工单创建**：支持手动创建和从告警自动转化
- **状态流转**：支持工单状态在待处理→处理中→待验收→已完成→已关闭之间的流转
- **工单处理**：支持接受、处理、完成、验收、关闭、驳回等操作
- **日志记录**：完整的操作日志追踪系统

### 3. 工单详情抽屉
- **沉浸式详情展示**：提供详细的工单信息查看
- **溯源信息**：显示与工单关联的原始告警信息
- **处理流程时间轴**：可视化展示工单处理全过程
- **动态操作按钮**：根据工单当前状态提供相应操作选项

### 4. 创建工单模态框
- **表单验证**：完善的输入验证机制
- **字段齐全**：包含标题、类型、优先级、截止时间、库区、设备、责任人等必要字段
- **告警关联**：支持与现有告警关联创建

### 5. 与告警系统集成
- **告警转工单**：从告警中心可以直接将告警转化为工单
- **状态同步**：工单处理会影响关联告警的状态
- **闭环管理**：实现告警→工单→解决的完整闭环

## 工单状态流转

1. **PENDING（待处理）**：工单创建后的初始状态
2. **PROCESSING（处理中）**：工单被接受后进入处理状态
3. **VERIFYING（待验收）**：工单处理完成后等待验收
4. **COMPLETED（已完成）**：工单验收通过后的状态
5. **CLOSED（已关闭）**：工单最终关闭状态

## 工单类型

1. **ALERT_DEFECT（告警消缺）**：由系统告警转化而来的工单
2. **ROUTINE_INSPECTION（日常巡检）**：定期巡检任务
3. **EQUIPMENT_MAINTENANCE（设备维保）**：设备维护保养工单

## 工单优先级

1. **LOW（低）**：低优先级任务
2. **MEDIUM（中）**：中等优先级任务
3. **HIGH（高）**：高优先级任务
4. **URGENT（紧急）**：紧急处理任务

## 数据库设计

### 工单主表 (work_orders)
- 基础信息：ID、标题、描述、状态、优先级、类型
- 关联信息：责任人、报告人、关联告警ID
- 时间信息：创建时间、截止时间、完成时间、验收时间
- 位置信息：库区、设备、详细位置

### 工单日志表 (work_order_logs)
- 操作记录：工单ID、操作动作、操作人
- 状态变更：变更前状态、变更后状态
- 时间记录：操作时间、备注信息

## API接口

### 工单管理API
- `POST /api/work-orders`：创建工单
- `GET /api/work-orders/{id}`：获取工单详情
- `GET /api/work-orders`：获取工单列表（支持分页和筛选）
- `PUT /api/work-orders/{id}/status`：更新工单状态
- `PUT /api/work-orders/{id}`：更新工单信息
- `GET /api/work-orders/{id}/logs`：获取工单日志
- `GET /api/work-orders/stats`：获取工单统计信息

## 使用场景

### 日常运维
1. 通过告警中心发现问题
2. 将紧急告警转化为工单进行跟踪
3. 分配给相应责任人处理
4. 跟踪处理过程直至闭环

### 预防性维护
1. 创建设备维保工单
2. 按计划执行维护任务
3. 记录维护过程和结果

### 质量管理
1. 通过工单追溯问题源头
2. 分析处理效率和质量
3. 持续改进运维流程
