# 冷链守护 - 微信小程序端

基于UI/UX设计原则的冷链仓储安全管理系统移动端，专为内部员工设计，具有“去伪存真、大字号、防误触、聚焦任务”的特点。

## 设计原则

* **色彩语义化**：严格使用颜色区分状态，不要让员工靠阅读文字来判断严重性
  * 🔴 **红色 (#F56C6C)**：紧急告警、逾期工单、超温严重
  * 🟠 **橙色 (#E6A23C)**：高危告警、设备离线、即将逾期
  * 🔵 **蓝色 (#409EFF)**：处理中的正常状态、主要操作按钮
  * 🟢 **绿色 (#67C23A)**：已恢复正常、已闭环

* **防误触设计**：所有可点击按钮（Button）和卡片（Card）高度至少 `44px` 以上，确保戴薄手套也能精准点击

## 页面结构

### 1. 🏠 工作台 (pages/workbench/)
* 顶部欢迎区：员工姓名、班次、天气信息
* 核心操作区：[扫一扫] 和 [语音报修] 巨大按钮
* 高频数据看板：待处理任务数、今日完成数
* 紧急任务列表：高优先级任务高亮显示

### 2. 🔔 告警大厅 (pages/alert/)
* 顶部过滤：未处理 / 处理中 Tab
* 告警卡片列表：颜色边框区分等级，清晰显示当前值和阈值
* 快捷操作：误报消除、一键转工单

### 3. 📋 工单处理 (pages/workorder/)
* 工单列表：待接收 / 待处理 / 已完成 Tab
* 工单详情：扫码签到、现场拍照、处理记录、提交验收

### 4. 👤 个人中心 (pages/profile/)
* 基本信息：头像、姓名、部门
* 绩效数据：完成率、处理数量
* 消息设置：自定义接收哪些区域推送
* 离线数据中心：查看和同步本地数据

## 技术特点

* 使用 Skyline 渲染引擎提升性能
* Glass-Easel 组件框架
* 遵循微信小程序开发规范
* 适配安全区域（刘海屏、底部小黑条）

## 快速开始

1. 使用微信开发者工具打开项目根目录
2. 确保已安装最新版微信开发者工具
3. 项目会自动使用 Skyline 渲染引擎
